## Objective

Extend `src/app/db/migrations/0002_agent_runtime_and_hybrid_search.sql` with `CTX_DDL` `MULTI_COLUMN_DATASTORE` preferences (`product_search_ds`, `store_search_ds`) and `SYNC (ON COMMIT)` `CTXSYS.CONTEXT` indexes (`product_hybrid_ctx_idx`, `store_hybrid_ctx_idx`), replace the unused `intent_exemplar` table with `chat_route` (including `chat_route_ctx_idx` and `chat_route_embedding_idx`), create curated route exemplars in `src/app/db/fixtures/chat_route.json`, and wire `chat_route` into `src/app/db/utils.py`, `src/app/cli/_helpers/embeddings.py`, and `src/app/cli/_helpers/fixtures.py`.

## Context

- `src/app/db/migrations/0001_cymball_coffee_products.sql:46-47` creates `product_name_idx` and `product_desc_idx` without `SYNC (ON COMMIT)` and without indexing `category`, `origin`, `roast_level`, `flavor_profile`, or store location fields (`CP-09`).
- `0001_cymball_coffee_products.sql:122-135` creates `intent_exemplar`, which has no fixtures or SQL queries.
- `src/app/db/utils.py:18-24` defines `FIXTURE_TABLES = ["product", "coffee_store", "store_product_inventory"]`. Adding `"chat_route"` ensures `coffee upgrade`, `coffee bulk-embed`, and `coffee export-fixtures` manage route exemplar embeddings alongside product embeddings.

## Steps

  1. `FIXTURE_TABLES` in `src/app/db/utils.py` includes `"chat_route"` and `src/app/db/fixtures/chat_route.json` loads 20+ exemplars covering `PRODUCT_RAG`, `PRODUCT_AVAILABILITY`, `STORE_LOCATION`, `ORDER_STATUS`, and `GENERAL_CONVERSATION` with 3,072-float `embedding` arrays.

- [ ] **Step 2 (Migration `0002` Hybrid DDL)**: Append to `src/app/db/migrations/0002_agent_runtime_and_hybrid_search.sql` (`migrate-0002-up` and `migrate-0002-down`):
  1. Drop legacy `product_name_idx`, `product_desc_idx`, and `intent_exemplar`.
  2. Create `CTX_DDL` `MULTI_COLUMN_DATASTORE` preferences `product_search_ds` (`name, category, origin, roast_level, flavor_profile, description`) and `store_search_ds` (`name, city, state, address_line1, postal_code, neighborhood, notes`).
  3. Create `product_hybrid_ctx_idx ON product(description) INDEXTYPE IS CTXSYS.CONTEXT PARAMETERS ('DATASTORE product_search_ds SYNC (ON COMMIT)')` and `store_hybrid_ctx_idx ON coffee_store(notes) INDEXTYPE IS CTXSYS.CONTEXT PARAMETERS ('DATASTORE store_search_ds SYNC (ON COMMIT)')`.

Create `chat_route` (`id NUMBER GENERATED BY DEFAULT ON NULL AS IDENTITY PRIMARY KEY`, `route_label VARCHAR2(64) NOT NULL`, `title VARCHAR2(200) NOT NULL`, `exemplar_text CLOB NOT NULL`, `keywords VARCHAR2(1000) NOT NULL`, `embedding VECTOR(3072, FLOAT32)`, `created_at TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP NOT NULL`) with `chat_route_ctx_idx` (`SYNC (ON COMMIT)`) and HNSW `chat_route_embedding_idx`.
