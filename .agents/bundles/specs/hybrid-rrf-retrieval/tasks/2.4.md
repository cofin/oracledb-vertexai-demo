## Context

- `src/app/domain/ai/services/agent_service.py:22-42` currently builds an `AgentNode` with `tools=()`.
- When `HybridRouteResolver.resolve_turn` returns `is_deterministic=True`, `AgentOrchestrationService` executes the grounded composer (`PRODUCT_RAG`, `PRODUCT_AVAILABILITY`, `STORE_LOCATION`, or `ORDER_STATUS`), persists the user and assistant `AgentEvent` rows to `OracleEventStore`, records search metrics, caches location-independent responses in `ResponseCacheService`, and emits the complete `ChatResponse` (or SSE `delta` + `final` stream).
- When `is_deterministic=False` (`GENERAL_CONVERSATION` or multi-intent turns), `AgentOrchestrationService` runs `AgentRuntime` with the 5 closure-bound tools and pre-fetched hybrid candidates injected into `CallContext.services`.
