## Objective

`make test-adb` runs acceptance tests against the developer's running ADB-Free container (after `make start-infra` and `uv run coffee upgrade`) and proves the composed runtime: the app pool connects as `APP` over `tcps`, the queue pool is a separate wallet pool, migrations produced valid HNSW and Oracle Text indexes, the elastic vector pool is allocated, HNSW and hybrid RRF queries return rows, walletless TLS behaves as observed, and bad credentials are refused. Default `make test` and `make test-integration` skip these tests with a reason.

## Context

- Phase 1 delivered the container, wallet, provisioning, CLI, and managed `.env` (`DATABASE_URL`, `WALLET_PASSWORD`, `TNS_ADMIN`, `ORACLE_ADMIN_PASSWORD`).
- `src/tests/AGENTS.md`: exactly three `conftest.py` files; shared fixtures live in `src/tests/fixtures/*.py` registered in `src/tests/conftest.py::pytest_plugins` (today `["tests.fixtures.slides"]`); no `unittest.mock` under `integration/` or `fixtures/`.
- `src/tests/integration/conftest.py` adds the `oracle_integration` xdist group to every integration item, and its `test_settings`/`oracle_test_container` fixtures are only created when requested, so ADB tests that use only ADB fixtures start no gvenzl container. Its `test_settings` shows the pattern for pointing `app_config` at a database: write `.env.testing`, clear env keys, `Settings.from_env.cache_clear()`, `Settings.from_env(path)`, patch `app_settings.get_settings`, `app_config._reset()`.
- `Settings.from_env()` uses `load_dotenv(override=False)`, so shell values win; the fixture clears database keys first with the `monkeypatch.setenv(key, "x")` then `monkeypatch.delenv(key)` pattern, which also restores them at teardown.
- Named SQL: `vector-search-products`, `explain-plan-vector-search`, `explain-plan-display` (`src/app/db/sql/products.sql`, `system.sql`) and `hybrid-search-turn` (binds `has_text_query`, `text_query`, `query_vector`, `rrf_k`, `limit`) in `src/app/db/sql/hybrid.sql`. Mirror the call style of `ProductService.search_by_vector` (`src/app/domain/products/services/_products.py`).
- Index names from migration 0001: HNSW `PRODUCT_EMBEDDING_IDX`, `CHAT_ROUTE_EMBEDDING_IDX`; Oracle Text `PRODUCT_HYBRID_CTX_IDX`, `STORE_HYBRID_CTX_IDX`, `CHAT_ROUTE_CTX_IDX`.
- `V$VECTOR_MEMORY_POOL` columns: `POOL`, `ALLOC_BYTES`, `USED_BYTES`, `POPULATE_STATUS`, `CON_ID` (research F10). Walletless TLS needs `adb_container.cert`, which the wallet export copies (F5); research C1 leaves the TLS port behavior open.
