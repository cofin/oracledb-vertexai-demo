## Objective

`uv run python manage.py database select-ai setup` creates (or recreates) the `GEMINI_CRED` credential and the `COFFEE_GEMINI` Select AI profile for the app schema on ADB-Free, matching slide 13. `uv run python manage.py database select-ai ask "which stores have Ethiopian beans in stock"` prints the result of `DBMS_CLOUD_AI.GENERATE` (default action `showsql`). The API key comes only from `SELECT_AI_GEMINI_API_KEY`, is bound as a SQL parameter, and is never printed.

## Context

- Task 1.2 granted `EXECUTE ON DBMS_CLOUD_AI` and the HTTP ACE for `generativelanguage.googleapis.com`; `DWROLE` covers `DBMS_CLOUD` (research F12).
- Slide 13 (`.agents/bundles/knowledge/presentation/storyboard-opening-and-part1.md`) shows `DBMS_CLOUD.CREATE_CREDENTIAL(credential_name => 'GEMINI_CRED', username => 'GOOGLE', password => '<gemini-api-key>')` and `DBMS_CLOUD_AI.CREATE_PROFILE(profile_name => 'COFFEE_GEMINI', attributes => '{"provider": "google", "credential_name": "GEMINI_CRED", "model": "gemini-3.5-flash", "object_list": [{"owner": "APP"}]}')`.
- Decision D11: dedicated `SELECT_AI_GEMINI_API_KEY` with no `GOOGLE_API_KEY` fallback; `SELECT_AI_PROFILE`, `SELECT_AI_CREDENTIAL`, and `SELECT_AI_MODEL` override the defaults.
- `ConnectionConfig.from_env().to_connect_params()` (Task 1.4) produces wallet connection parameters from `DATABASE_URL`, `TNS_ADMIN`, and `WALLET_PASSWORD`.
- `tools/oracle/cli/database.py::_load_env_file(env_file)` loads `.env`; `manage.py` mounts `wallet` and `connect` on its `database` group from `tools.oracle` exports.
- Behind a proxy, `DBMS_CLOUD_CONTAINER_ADMIN.set_database_property('HTTP_PROXY', 'host:port/')` enables egress (research F13).
