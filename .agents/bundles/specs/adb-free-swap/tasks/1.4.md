## Objective

`uv run python manage.py init --mode managed` writes an `.env` that runs the app over the ADB-Free wallet, and every tool treats that `.env` as managed. `manage.py doctor` warns about host CPU, memory, and the wallet. The SQLcl saved connection used by SQLcl MCP connects through the wallet alias. A unit test proves the generated `.env` produces wallet-mode app and queue pools with LOB isolation intact.

## Context

- `tools/lib/utils.py::create_env_interactive()` writes a managed block with `DATABASE_HOST/PORT/SERVICE_NAME=freepdb1`; `detect_deployment_mode()` returns `external` whenever `DATABASE_HOST` or `DATABASE_URL` is set; `configure_sqlcl_connection_with_password()` builds `user/password@//host:port/service` only; `generate_secret_key()` and `configure_sqlcl_connection_with_password()` use function-scoped imports.
- `tools/oracle/connection.py` has its own `detect_deployment_mode()`, `ConnectionConfig.for_managed()` with stale defaults (`Super-secret1`, `myatp_low` without a wallet), and `ConnectionTester._connection_params()` (private) building `user`, `password`, `dsn`, `wallet_password`, `wallet_location`, and `config_dir`.
- `tools/cli/doctor.py`: managed mode checks the runtime and warns below 8.5 GB memory; `--json` prints through `console.print`, which can wrap lines and break JSON.
- `tools/cli/init.py`: managed next steps list `make install`, `make start-infra`, `coffee upgrade`, `coffee run`.
- `src/app/lib/settings/_database.py`: `is_autonomous` = `URL` and `WALLET_PASSWORD`; `_build_pool_config()` requires `WALLET_LOCATION` (or `TNS_ADMIN`), resolves it, sets `os.environ["TNS_ADMIN"]`, and loads `ewallet.pem` into an `ssl_context` when present. `Settings.from_env()` calls `load_dotenv(override=False)` and mutates `os.environ`, so this test builds `DatabaseSettings()` directly from env vars set with `monkeypatch`.
- `tools/oracle/adb.py` (Task 1.2) exports `validate_adb_password()` and `validate_wallet_password()`.

## Steps

- [ ] **Step 1 (Red)**: Create `src/tests/unit/tools/test_managed_env.py` (5-section layout). Every test that writes files calls `monkeypatch.chdir(tmp_path)`. Tests:
  1. `test_managed_env_writes_adb_wallet_block`: `create_env_interactive("managed", non_interactive=True)` writes `.env` containing exactly these lines: `DATABASE_DEPLOYMENT_MODE=managed`, `ORACLE_CONTAINER_FLAVOR=adb-free`, `DATABASE_URL=oracle+oracledb://app:SuperSecret1@myatp_low`, `WALLET_PASSWORD=SuperSecret1`, `TNS_ADMIN=.envs/tns`, `ORACLE_ADMIN_PASSWORD=SuperSecret1`, and no `DATABASE_SERVICE_NAME=freepdb1` or `DATABASE_HOST=` line.
  2. `test_external_env_records_explicit_mode`: the external non-interactive output contains `DATABASE_DEPLOYMENT_MODE=external`.
  3. `test_detect_deployment_mode_prefers_explicit_setting` (parametrized): `managed` plus `DATABASE_URL` gives `managed`; `external` with nothing else gives `external`; unset with `DATABASE_URL` gives `external`; unset with nothing gives `managed`; `bogus` falls back to the heuristic. Assert `tools.oracle.connection.detect_deployment_mode()` returns the same value in each case.
  4. `test_managed_env_yields_wallet_mode_settings_with_isolated_queue_pool`: generate `.env`; for each pair from `dotenv_values(".env")` call `monkeypatch.setenv`; build `DatabaseSettings()`. Assert `is_autonomous`; that both `get_config().connection_config` and `get_queue_config().connection_config` have `dsn == "myatp_low"`, `wallet_location == config_dir == str((tmp_path / ".envs" / "tns").resolve())`, and `wallet_password == "SuperSecret1"`; that the app config has `driver_features["enable_AutoLob"] is True`; that the queue config has `driver_features["fetch_lobs"] is False` and `extension_config["litestar"]["session_key"] == "queue_db_session"`.
  5. `test_wallet_mode_requires_wallet_location`: `DatabaseSettings(URL="oracle+oracledb://app:SuperSecret1@myatp_low", WALLET_PASSWORD="SuperSecret1", WALLET_LOCATION=None).get_config()` raises `ValueError`.

The captured `input` contains `conn -save cymbal_coffee -savepwd app/SuperSecret1@myatp_low`, and `env["TNS_ADMIN"] == str((tmp_path / ".envs" / "tns").resolve())`.
