## Objective

`OracleDatabase.start()` brings up `container-registry.oracle.com/database/adb-free:latest-26ai` by default, waits for its listener, and leaves a validated mTLS wallet in `WALLET_LOCATION` (default `.envs/tns`) on every start path. `ORACLE_CONTAINER_FLAVOR=free` keeps today's gvenzl behavior unchanged, and the ephemeral integration-test container requests that flavor explicitly.

## Context

- `tools/oracle/database.py` today: gvenzl-only `DatabaseConfig` (container `oracle-free-db`, volume `oracle-db-data`, port 1521, fields `app_user`/`app_user_password`) and `OracleDatabase.start()` with three paths: running (reuse plus `_align_app_user_credentials`), stopped (`start`), and fresh (volume, `run`, `wait_for_healthy(300)`). `_build_run_command()` mounts `tools/oracle/on_init/*` and `tools/oracle/on_startup/*` into the gvenzl hook directories; `exec_sql()` runs in-container sqlplus.
- June ADB-Free implementation: `git show a7b9112:tools/oracle/database.py`. Reuse the README run flags, `--hostname db`, `--shm-size 2g`, and the `lsnrctl status | grep -qi 'myatp_low.adb.oraclecloud.com'` health check. Do not reuse the `/dev/shm` bind mounts, the audit and oradata mounts, the host bind mount of the wallet directory, `busybox chmod -R 777`, or the SYSDBA vector-memory bounce (ORA-01017 in ADB-Free).
- Oracle README contract (research F3-F5): `-p 1521:1522 -p 1522:1522 -p 8443:8443`, `WORKLOAD_TYPE=ATP`, `ADMIN_PASSWORD`, `WALLET_PASSWORD`, `ENABLE_ARCHIVE_LOG=FALSE`, `--cap-add SYS_ADMIN --device /dev/fuse`, a volume at `/u01/data`, the wallet at `/u01/app/oracle/wallets/tls_wallet`, aliases `myatp_low` (mTLS) and `myatp_low_tls` (TLS). The Mongo port 27017 is not mapped (D9 scope).
- `tools/oracle/container.py::ContainerRuntime.run_command(args, *, capture_output, check, timeout)` accepts `["cp", "<container>:<path>/.", "<host dir>"]` for Docker and Podman; the copied files belong to the invoking user.
- `tools/oracle/wallet.py::WalletConfigurator.validate_wallet()` checks `cwallet.sso`, `tnsnames.ora`, and `sqlnet.ora` and parses alias names.
- `src/tests/integration/conftest.py::oracle_test_container` builds `DatabaseConfig(container_name=..., host_port=..., app_user=..., app_user_password=..., data_volume_name=...)`. With the ADB default it must pass `flavor=ContainerFlavor.FREE`.
- `src/tests/unit/test_test_suite_guards.py` bans `src/tests/unit/tools/oracle/`; tool tests are flat files under `src/tests/unit/tools/`.
- `tools/oracle/` is outside `tools/ci/check_code_hygiene.py`, but `.agents/AGENTS.md` forbids inline `#` comments in `tools/`. Remove the inline comments in `database.py` while rewriting it; keep `# ruff: ignore[...]` pragmas only where a rule still fires.
