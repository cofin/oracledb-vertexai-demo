## Objective

Configure `litestar-queues[sqlspec]>=0.12.0` on Oracle 26ai by:
1. Adding `"litestar-queues[sqlspec]>=0.12.0"` to `pyproject.toml`.
2. Creating `src/app/lib/settings/_queue.py` (`QueueSettings` with `enabled: bool = True`, `backend: Literal["sqlspec", "memory"] = "sqlspec"`, `execution_backend: Literal["asgi", "standalone", "none"] = "asgi"`, `wakeup_mode: Literal["polling", "oracle_aq"] = "polling"`, `concurrency: int = 4`, `poll_interval: float = 2.0`, `manage_schema: bool = True`, and `in_memory: bool` fallback when `ORACLE_QUEUE_IN_MEMORY=true`).
3. Adding `DatabaseSettings.get_queue_config()` in `src/app/lib/settings/_database.py` that returns a **separate** `OracleAsyncConfig` (`extension_config={"litestar": {"session_key": "queue_db_session"}}`, `min_sessions=1`, `max_sessions=4`) so `SQLSpecBackend._disable_oracle_lob_wrapping` (`enable_AutoLob=False`) never mutates the main application `config.db` (`enable_AutoLob=True`).
4. Wiring `QueuePlugin` and `AutowirePlugin(..., integrations=["dishka", "queues"])` in `src/app/server/plugins.py` and providing `QueueService` in `src/app/ioc/_database.py`.

## Context

- `SQLSpecBackend._disable_oracle_lob_wrapping` mutates the `OracleAsyncConfig` passed to `SQLSpecBackendConfig` by setting `driver_features["enable_AutoLob"] = False`. If `config.db` is passed directly, all application CLOB columns return `AsyncLOB` objects instead of `str`, breaking `json.loads()` across `OracleSessionStore`, `OracleEventStore`, and `ResponseCacheService`.
- Using a dedicated `OracleAsyncConfig` from `DatabaseSettings.get_queue_config()` isolates the LOB setting completely.
