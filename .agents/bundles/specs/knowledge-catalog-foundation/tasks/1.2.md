## Objective

Implement the one-command Knowledge Catalog seeder and OKF v0.2 exporter (`uv run coffee sync-catalog`) in `src/app/cli/_helpers/catalog.py` and `src/app/cli/commands.py`, backed by a committed fixture (`src/app/db/fixtures/knowledge_catalog_context.json`) and OKF v0.2 catalog index (`.agents/bundles/knowledge/catalog/index.md`) so the demo can be configured and verified in seconds either against a live GCP project (`--push`) or completely offline (`--from-fixture` / `--export-okf`).

## Context

- `src/app/cli/commands.py:147-223` defines top-level `coffee` CLI commands using `@cli.command(...)` and `@async_inject`.
- Per `AGENTS.md:67-74`, substantial CLI workflows live in `src/app/cli/_helpers/<module>.py` while `src/app/cli/commands.py` stays declarative.
- `dataplex.googleapis.com/v1` exposes REST endpoints to upsert an `EntryGroup` (`POST /v1/projects/{p}/locations/{l}/entryGroups?entryGroupId={eg}`) and `Entry` records (`PATCH /v1/projects/{p}/locations/{l}/entryGroups/{eg}/entries/{entry_id}?allowMissing=true`) with global system aspects (`projects/655216118709/locations/global/aspectTypes/{schema,overview,guidelines,queries}`).
- `GoogleCloudPlatform/knowledge-catalog/okf/SPEC.md` (`OKF v0.2`) defines Markdown concept files with YAML frontmatter (`okf_version: "0.2"`, `type`, `title`, `description`, `resource`, `verified: human-reviewed`, `tags`) that can be pushed via `npx -y kcmd push <project> <location> <entry-group> --path .agents/bundles/knowledge/catalog --format okf`.
