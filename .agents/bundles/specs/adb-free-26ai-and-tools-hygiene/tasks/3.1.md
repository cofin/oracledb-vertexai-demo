## Objective

Implement the managed `container-registry.oracle.com/database/adb-free:latest-26ai` lifecycle (`cymbal-adb-free`, ports `1521:1522`, `1522:1522`, `8443:8443`, `/u01/data` volume), automated mTLS wallet export and validation via `sqlspec.adapters.oracledb`, idempotent `ADMIN` schema/ORDS/APEX `COFFEE` workspace bootstrap (`tools/oracle/adb.py`), explicit `DATABASE_DEPLOYMENT_MODE` resolution (`tools/oracle/connection.py`), and `ORACLE_CONTAINER_FLAVOR="free"` isolation for `src/tests/integration/conftest.py`.

## Context

- `container-registry.oracle.com/database/adb-free:latest-26ai` (`26.9.4.1-26ai`) bundles Oracle AI Database 26ai, APEX 26.1.5, and ORDS 26.3 on HTTPS `:8443`, exposing mTLS services (`myatp_high`, `myatp_medium`, `myatp_low`, `myatp_tp`, `myatp_tpurgent`) on container port `1522` with its pre-built wallet at `/u01/app/oracle/wallets/tls_wallet` and persistent data at `/u01/data`.
- `tools/oracle/container.py:156-165` (`container_exists`) currently invokes `run_command(["ps", "-a", ...])` twice for every lookup and contains inline `#` comments.
- `tools/oracle/wallet.py:450` prints `DATABASE_USERNAME=<your_username>` instead of `DATABASE_USER=<your_username>` and contains inline `#` comments and function-scoped imports.
- `tools/oracle/connection.py:59-102` treats any `DATABASE_URL` (`myatp_low`) as `DeploymentMode.EXTERNAL` unless `DATABASE_DEPLOYMENT_MODE=managed` is honored, and imports `re` inside `ConnectionConfig.from_env`.

  1. Write unit tests covering:
     - `DatabaseConfig.from_env()` defaulting `flavor` to `ContainerFlavor.ADB_FREE` (`image="container-registry.oracle.com/database/adb-free:latest-26ai"`, `container_name="cymbal-adb-free"`, `https_port=8443`, `service_name="myatp_low"`, `wallet_dir=Path(".envs/tns")`) and switching cleanly to `ContainerFlavor.FREE` (`gvenzl/oracle-free:latest`, `oracle-free-db`, `freepdb1`) when `ORACLE_CONTAINER_FLAVOR="free"`.
     - `ContainerRuntime.container_exists` invoking `ps -a` once per check, and `OracleDatabase` refusing to start `cymbal-adb-free` with a clear actionable error (`uv run python manage.py infra wipe --volumes --force --yes`) when a running `oracle-free-db` container already binds host port `1521`.
     - Constructing the `adb-free` `docker run` argument vector with `-p 1521:1522`, `-p 1522:1522`, `-p 8443:8443`, `-v cymbal-adb-data:/u01/data`, `-e WORKLOAD_TYPE=ATP`, `-e ENABLE_ARCHIVE_LOG=FALSE`, `-e WALLET_PASSWORD=...`, `-e ADMIN_PASSWORD=...`, `--cap-add SYS_ADMIN`, `--device /dev/fuse`, and `--add-host=host.docker.internal:host-gateway` on Linux Docker.
