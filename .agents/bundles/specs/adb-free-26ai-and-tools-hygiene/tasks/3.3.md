## Objective

Move `configure-apex-cdn.sql` and `revert-apex-cdn.sql` into `src/app/db/sql/deploy/` so wheel and PyApp distroless Cloud Run images bundle them automatically, update `src/app/cli/_helpers/ords.py` (`Settings.from_env()`, packaged SQL path, wallet/`ADMIN` or `SYSDBA` support), verify `tools/deploy/docker/Dockerfile` and `tools/deploy/gcp/cloudbuild.yaml` build alignment, fix the character-by-character string iteration bug in `tools/cli/install.py:314`, and modernize `tools/lib/utils.py`, `tools/cli/init.py`, and `tools/cli/doctor.py` for `adb-free:latest-26ai`.

## Context

- `src/app/cli/_helpers/ords.py:48` computes `BASE_DIR.parents[1] / "tools" / "deploy" / "gcp" / "configure-apex-cdn.sql"`, which fails inside the distroless PyApp image (`tools/deploy/gcp/cloudbuild.yaml:79-89`, `args: ["configure-apex-cdn"]`) because `pyproject.toml:138` packages `src/app/**/*.sql` and excludes `tools/`.
- `tools/deploy/docker/Dockerfile:44` copies `dist/coffee-${TARGETARCH}-linux-gnu`, so `tools/deploy/gcp/cloudbuild.yaml:38-49` must either build via a multi-stage PyApp/wheel prep stage in `Dockerfile` when pre-built `dist/` artifacts are absent or build the onefile binary prior to `docker build` so `gcloud builds submit` succeeds cleanly from a git checkout.
- `tools/cli/install.py:314` loops `for instruction in installer.get_path_instructions():` over a `str`, printing one character per line.
- `tools/lib/utils.py:170` writes `LITESTAR_PORT=5006` (diverging from `8000` everywhere else), writes `freepdb1` instead of `adb-free` wallet defaults (`DATABASE_DEPLOYMENT_MODE=managed`, `DATABASE_URL=myatp_low`, `WALLET_LOCATION=./.envs/tns`, `WALLET_PASSWORD=SuperSecret1`), calls `json.load`/`json.dumps` directly, and carries unused helpers on lines `295-420`.
