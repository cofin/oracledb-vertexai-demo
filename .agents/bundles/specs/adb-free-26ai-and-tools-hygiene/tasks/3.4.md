## Objective

Bring the remaining `tools/` modules (`sqlcl_installer.py`, `cli/connection.py`, `cli/wallet.py`, `bundler.py`, `license_headers.py`, `generate_inventory_fixtures.py`, and package `__init__.py` files) into full compliance with repository hygiene rules, update `Makefile` (`start-infra` and `apex` targets) for persistent `cymbal-adb-free`, and expand `tools/ci/check_code_hygiene.py` to enforce inline-comment and AST rules across every Python file in `src/app/`, `tools/`, and `manage.py`.

## Context

- `Makefile:375-386` runs `uv run python manage.py infra start --recreate --skip-apex --skip-ords` in `start-infra` (which would destroy the persistent `cymbal-adb-free` container on every run and pass removed flags) and describes `make apex` as installing APEX + starting the ORDS sidecar.
- `tools/oracle/sqlcl_installer.py` (`import subprocess` inside `get_version` at line 170, unslotted dataclasses, inline `#` comments), `tools/oracle/cli/{connection,wallet}.py`, `tools/bundler.py`, `tools/license_headers.py`, and `tools/scripts/generate_inventory_fixtures.py` still contain inline `#` comments, nested imports, or missing `tools/scripts/__init__.py`.
- `tools/ci/check_code_hygiene.py:106-116` currently checks only `src/app`, `tools/slides`, `tools/ci`, and inline comments in `manage.py`.
