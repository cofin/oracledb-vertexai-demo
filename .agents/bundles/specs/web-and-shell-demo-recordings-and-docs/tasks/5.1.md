## Objective

Create the deterministic terminal/SQLcl video recording module (`tools/demos/shell.py`), two tracked `vhs` tape definitions (`docs/_tapes/apex-vertex-ai-setup.tape` and `docs/_tapes/apexlang-workflow.tape`), and the interactive confirmation wrapper (`tools/scripts/record-live-demos.sh`) so terminal walkthroughs of configuring APEX 26.1 with Direct Vertex AI and validating/importing the Cymbal Coffee APEXlang app render reproducibly to `.mp4` and `.gif`.

## Context

- `vhs` (`v0.11.0`) uses Go `rod` to drive headless Chromium via `ttyd` and `ffmpeg`. On Linux workstations without `/usr/bin/google-chrome`, `rod` requires `ROD_BROWSER_BIN` pointing to an installed Chromium binary (such as `~/.cache/ms-playwright/chromium-*/chrome-linux/chrome`) and `VHS_NO_SANDBOX=true`.
- Every `.tape` file must declare `Output docs/_static/demos/<name>.mp4` and `Output docs/_static/demos/<name>.gif`, use `Hide` ... `Show` around environment preparation so zero credentials or noisy prompts appear on screen, and synchronize steps with `Wait+Screen` regexes rather than brittle sleeps alone.
