## Objective

Refactor `src/app/domain/ai/` and `src/app/db/sql/ai-runtime.sql` so `OracleSessionStore` and `OracleEventStore` inherit from `OracleLoaderService` (`self.provide_app_session()`, `self.get_sql(...)`) with SQL `:limit` pushdown and centralized `app.utils.serialization`, migrate runtime wire structs to `FrozenBaseStruct`, delete unused `RunContextRegistry`, `CoffeeToolServices`, and dead `EmbeddingService` / `InventoryService` / `MapsService` references from `CoffeeToolContext` and `_agent.py`, and standardize private module naming (`a2a/{_card,_executor}.py`, `services/{_agent,_history}.py`).

## Context

- `src/app/db/sql/ai-runtime.sql:55-78` (`list-ai-events`) fetches every event in a session and slices `[:limit]` in Python (`runtime/_store.py:160-185`) instead of pushing `FETCH FIRST :limit ROWS ONLY` into Oracle 26ai SQL.
- `src/app/domain/ai/runtime/_store.py:1-187` imports `from app.config import db_manager` and `json.loads` / `msgspec.json.encode` directly instead of inheriting from `OracleLoaderService` and using `app.utils.serialization`.
- `src/app/domain/ai/runtime/_context.py:27-108` defines `RunContextRegistry` (never used anywhere in production) and carries legacy `embedding_service`, `inventory_service`, and `maps_service` fields on `CoffeeToolContext`. Removing those legacy imports here in Task `2.3` allows Task `2.4` to delete `InventoryService`, `MapsService`, and `EmbeddingService` from `products/services/` without breaking `ai/`.
- `src/app/domain/ai/a2a/{card,executor}.py` and `src/app/domain/ai/services/agent_service.py` (683 lines) use public module filenames instead of the repository's private `_*` module convention.
