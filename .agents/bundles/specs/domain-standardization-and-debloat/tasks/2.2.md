## Objective

Create `src/app/lib/text_search.py` to centralize Oracle Text reserved-word/token sanitization and proximity (`NEAR((...))`) query construction, migrate `src/app/domain/chat/` to `OracleLoaderService`, `FrozenBaseStruct`, `app.lib.exceptions.AIServiceUnconfigured`, and `chat/_session.py`, move `CoffeeChatForm` to `chat/schemas/_forms.py`, split Markdown route composers into `chat/services/_composers.py`, and expand `_KNOWN_CITY_FILTERS` to match all seeded Dallas-Fort Worth store cities.

## Context

- `src/app/domain/chat/services/_router.py:45-120` and `src/app/domain/products/services/_products.py:35-95` duplicate Oracle Text token escaping (`{token}`, reserved operators `AND`, `OR`, `NOT`, `NEAR`, `ACCUM`, `SYN`, `ABOUT`, `WITHIN`, `FUZZY`, stopwords).
- `src/app/domain/chat/services/_grounded.py` is 835 lines long, combining `GroundedRouteService` orchestration with deterministic Markdown response composers (`PRODUCT_RAG`, `STORE_LOCATION`, `PRODUCT_AVAILABILITY`, `ORDER_STATUS`).
- `src/app/domain/chat/services/_telemetry.py` (`_KNOWN_CITY_FILTERS`) misses seeded DFW cities (`plano`, `fort worth`, `arlington`, `frisco`, `irving`) present in `src/app/db/fixtures/store.json.gz`.
- `src/app/domain/chat/controllers/_helpers.py` defines the `CoffeeChatForm` schema inside `controllers/` instead of `chat/schemas/_forms.py`.
- Note: Leave `src/app/domain/chat/exceptions.py` and `src/app/domain/chat/session.py` untouched on disk until Task `2.4` updates `products/controllers/_vector.py` and `web/controllers/_pages.py` and deletes both legacy files cleanly.
