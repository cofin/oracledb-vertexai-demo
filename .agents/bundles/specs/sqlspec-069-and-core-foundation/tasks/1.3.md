## Objective

Delete unused security/ADK logging artifacts (`src/app/lib/log/_security.py` and `SuppressADKWarningsFilter`), eliminate every function-scoped import in `src/app/config.py` and `src/app/server/plugins.py` using `register_reset_hook`, decouple `setup_logging()` from `config._initialize()`, and tighten both `tools/ci/check_code_hygiene.py` and `src/tests/unit/test_test_suite_guards.py` so only `src/app/cli/{commands,main}.py` may use lazy function-scoped imports.

## Context

- `src/app/lib/log/_security.py:1-54` (`apply_security_headers`, `build_security_headers`) duplicates `SecurityPlugin` in `src/app/lib/security.py`, while `BeforeSendHandler` in `src/app/lib/log/_middleware.py` handles structured HTTP request/response logging.
- `src/app/lib/log/_filters.py:25-58` and `src/app/config.py:160-210` still configure `SuppressADKWarningsFilter` and `google.adk.*` logger/warning filters even though `google-adk` is banned via Ruff `TID251`.
- `src/app/config.py:245-305` (`_reset`) performs a function-scoped `from app.server import plugins as server_plugins` import to reset plugin singletons, while `src/app/server/plugins.py` performs function-scoped imports inside plugin factory helpers.
- Because of those nested imports, `tools/ci/check_code_hygiene.py:34-41` (`ALLOWED_LAZY_IMPORT_FILES`) and `src/tests/unit/test_test_suite_guards.py:72-80` (`ALLOW_NESTED_IMPORTS`) currently exempt `config.py` and `server/plugins.py`.
