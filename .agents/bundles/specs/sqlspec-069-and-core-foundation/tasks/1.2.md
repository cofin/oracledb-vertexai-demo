## Objective

Establish the core value-object, serialization, error-handling, and SQL-loader service primitives in `src/app/lib/{schema,exceptions,service,security}.py` and `src/app/utils/serialization.py` so domain modules can use `FrozenBaseStruct` (`frozen=True, gc=False`), centralized `msgspec` JSON helpers, `ApplicationError` / `AIServiceUnconfigured`, and `OracleLoaderService` (`self.get_sql("<name>")`) without importing `app.config`.

## Context

- `src/app/lib/schema.py:1-16` defines `BaseStruct` and `CamelizedBaseStruct` without `frozen=True, gc=False`. Retaining `BaseStruct` and `CamelizedBaseStruct` during PR 1 keeps existing domain schemas green until PR 2 completes the domain migration and deletes them.
- `src/app/utils/serialization.py:1-60` defines `encode_json`, `from_json`, `to_json`, and `sanitize_for_json`, but domain modules still call `json.loads` / `msgspec.json.encode` directly because `encode_json_bytes`, `decode_json`, and `to_schema` are missing.
- `src/app/domain/chat/exceptions.py:1-12` and `src/app/domain/products/controllers/_vector_helpers.py:42-70` duplicate AI credential/unconfigured exception checks across domains instead of sharing `src/app/lib/exceptions.py`.
- `src/app/lib/service.py:1-41` (`OracleAsyncService`) lacks `__slots__ = ()`, cannot initialize from an `OracleAsyncConfig` for app-scoped stores (`provide_app_session()`), and lacks `SQLFileLoader` encapsulation (`OracleLoaderService`).
- `src/app/lib/security.py:21-52` defines `@dataclass(slots=True)` value objects that should be immutable (`frozen=True, slots=True`).

  ```python
  @lru_cache(maxsize=1)
  def default_sql_loader() -> SQLFileLoader:
      """Load and cache named SQL queries from src/app/db/sql."""
      sql_dir = Path(__file__).resolve().parents[1] / "db" / "sql"
      loader = SQLFileLoader()
      loader.load_sql(sql_dir)
      return loader


  class OracleAsyncService(SQLSpecAsyncService):
      """Oracle 26ai async data service supporting request drivers or app-scoped configs."""

      __slots__ = ()

      def __init__(
          self,
          driver_or_config: OracleAsyncDriver | OracleAsyncConfig,
          *,
          loader: SQLFileLoader | None = None,
      ) -> None:
          """Initialize the service with either an active driver session or an OracleAsyncConfig."""
          if isinstance(driver_or_config, OracleAsyncConfig):
              super().__init__(config=driver_or_config, loader=loader)
          else:
              super().__init__(driver_or_config, loader=loader)

      @property
      def driver(self) -> OracleAsyncDriver:
          """Return the bound request-scoped OracleAsyncDriver."""
          if self._session is None:
              msg = f"{type(self).__name__} was initialized with config only; use provide_app_session()."
              raise RuntimeError(msg)
          return cast("OracleAsyncDriver", self._session)

      @asynccontextmanager
      async def provide_app_session(self) -> AsyncIterator[OracleAsyncDriver]:
          """Yield an OracleAsyncDriver from either the bound session or the app-scoped pool."""
          async with self.provide_session() as session:
              yield cast("OracleAsyncDriver", session)

      async def commit(self) -> None:
          """Commit the active request-scoped transaction."""
          await self.driver.commit()

      async def execute_many(
          self,
          statement: Any,
          parameters: Sequence[ Any ],
          *,
          auto_commit: bool = False,
      ) -> Any:
          """Execute a batch DML statement and optionally commit."""
          async with self.provide_app_session() as session:
              result = await session.execute_many(statement, parameters)
              if auto_commit:
                  await session.commit()
              return result


  class OracleLoaderService(OracleAsyncService):
      """Oracle async service with an attached SQLFileLoader for named SQL lookup."""

      __slots__ = ()

      def __init__(
          self,
          driver_or_config: OracleAsyncDriver | OracleAsyncConfig,
          *,
          loader: SQLFileLoader | None = None,
      ) -> None:
          """Initialize with a driver or config and default to default_sql_loader()."""
          super().__init__(driver_or_config, loader=loader or default_sql_loader())

      def get_sql(self, name: str) -> Any:
          """Retrieve a named SQL statement from the attached SQLFileLoader."""
          if self._loader is None:
              return default_sql_loader().get_sql(name)
          return self._loader.get_sql(name)
  ```

## Notes & Discoveries

- `SQLFileLoader` is imported from `sqlspec.loader`. Dishka inspects every `__init__` parameter type annotation and rejects union parameters (`OracleAsyncDriver | OracleAsyncConfig`, `SQLFileLoader | None`), so `OracleLoaderService.__init__(self, driver: OracleAsyncDriver, loader: SQLFileLoader = cast("SQLFileLoader", None))` is used for Dishka request services while `_init_from_config(config, loader)` supports app-scoped pool stores.
