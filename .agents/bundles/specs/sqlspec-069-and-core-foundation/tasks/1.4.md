## Objective

Eliminate all `app.config` and `app.server` imports from `src/app/ioc/`, inject `Settings` / `SQLFileLoader` / `OracleAsyncConfig` cleanly across `ConfigProvider`, `DBProvider`, `AIProvider`, and `DomainServiceProvider`, promote `AgentStreamService` to `Scope.APP`, remove legacy provider/container aliases (`LitestarPersistenceProvider`, `IntegrationsProvider`, `make_container`), and update composition roots (`asgi.py`, `cli/main.py`, `cli/utils.py`, `lib/jobs.py`).

## Context

- Per `.agents/AGENTS.md` §2.5, provider modules under `src/app/ioc/` must never include `from __future__ import annotations` and must never import `app.config` or `app.server`.
- Currently:
  - `src/app/ioc/_database.py:11-55` imports `app.config` and `app.server.plugins` to resolve `db`, `queue_db`, and `QueueService`.
  - `src/app/ioc/_ai.py:16-192` imports `AIServiceUnconfigured` from `app.domain.chat.exceptions`, provides `AgentStreamService` at `Scope.REQUEST` instead of `Scope.APP`, and returns untyped `Any` for Vertex credentials.
  - `src/app/ioc/__init__.py:1-41` exports legacy aliases `IntegrationsProvider = AIProvider`, `LitestarPersistenceProvider = DBProvider`, and `make_container = create_container`.
  - `src/app/server/asgi.py`, `src/app/cli/main.py`, `src/app/cli/utils.py`, and `src/app/lib/jobs.py` call `make_container()` without passing the composition-root `db` / `queue_db` / `queue_service` instances.
  - `src/tests/unit/ioc/test_ioc_and_services.py:13-85` asserts those removed aliases (`IntegrationsProvider`, `LitestarPersistenceProvider`, `make_container`) and legacy domain service aliases (`EmbeddingService`, `ResponseCacheService`, `SystemService`).
