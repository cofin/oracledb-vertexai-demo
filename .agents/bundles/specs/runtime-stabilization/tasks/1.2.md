## Objective

Resolve blockers `AI-02`, `AI-06`, `AI-07`, `CP-01`, and `CP-02` so that:
1. `AgentRuntime.run_stream` (`src/app/domain/ai/runtime/_loop.py`) aggregates streaming model chunks into a final `partial=False` `AgentEvent` per model step, allowing `agent_service.py` to persist complete model turns with monotonic `seq` values and `AgentStreamService` (`_stream.py`) to set `has_final = True` instead of emitting `error: stream_incomplete`.
2. `Part`, `FunctionCall`, and `FunctionResponse` (`_types.py`, `_loop.py`, `_model.py`) preserve `call_id` and `thought_signature` across streaming chunks, JSON persistence, and `types.Content` reconstruction.
3. `function_to_schema` (`_schema.py`) outputs standard lowercase JSON Schema (`object`, `string`, `integer`, `number`, `boolean`, `array`).
4. `AgentStreamService.stream` (`_stream.py`) emits the complete `final` SSE payload required by `src/resources/chat-stream.js:297-305` (`answer`, `session_id`, `response_time_ms`, `intent_detected`, `search_metrics`, `from_cache`, `embedding_cache_hit`, `sql_phases`, `store_results`, `inventory_results`, `map_actions`, `location_context`, `turn`, `usage`).

## Context

- `src/app/domain/ai/runtime/_model.py:80-86` yields only `partial=True` chunks during `generate_stream`.
- `src/app/domain/ai/services/agent_service.py:119-123` checks `if not event.partial: await self._event_store.append_event(event)`.
- `src/app/domain/ai/runtime/_stream.py:165-177` checks `if not item.partial and item.content.role == "model": has_final = True`. Because no non-partial model event is ever emitted during streaming, every SSE stream ends with `{"type": "error", "error": "stream_incomplete"}` (`AI-02`, `CP-01`).
- `src/resources/chat-stream.js:297-305` reads `data.answer`, `data.session_id`, `data.response_time_ms`, `data.intent_detected`, `data.search_metrics`, `data.from_cache`, `data.embedding_cache_hit`, `data.sql_phases`, `data.store_results`, `data.inventory_results`, `data.map_actions`, and `data.location_context` from the `final` event (`CP-02`).
