## Objective

Fix blockers `AI-01`, `AI-04`, `AI-05`, and `AI-14` by creating the missing `agent_session` and `agent_event` tables in migration `0002_agent_runtime_and_hybrid_search.sql`, updating `src/app/db/sql/ai-runtime.sql` to target `agent_session` and `agent_event` (returning `seq` and `turn` in `list-agent-events` and adding `next-agent-event-seq`), and refactoring `OracleSessionStore` and `OracleEventStore` (`src/app/domain/ai/runtime/_store.py`) to run at `Scope.APP` over `db_manager.provide_session()` with explicit `await driver.commit()` calls.

## Context

- `src/app/db/sql/ai-runtime.sql:1-60` currently queries `adk_session` and `adk_event`, which do not exist in `0001_cymball_coffee_products.sql`.
- `src/app/domain/ai/runtime/_store.py:72-195` receives a request-scoped `AsyncOracleDriver` and never calls `await driver.commit()`, so every session/event write is rolled back when the connection returns to the pool.
- `list-agent-events` (`ai-runtime.sql:55-60`) omits `seq` and `turn` from its `SELECT` list, and `_store.py:173` hardcodes `seq=0`.
- `src/app/ioc.py:93-128` provides `SessionStore` and `EventStore` at `Scope.REQUEST` using `AsyncOracleDriver`. Moving them to `Scope.APP` with `SQLSpec` (`db_manager`) avoids transaction interleaving during SSE streaming and enables direct reuse in A2A and background tasks.

- [ ] **Step 2 (Migration `0002`)**: Create `src/app/db/migrations/0002_agent_runtime_and_hybrid_search.sql` with `-- name: migrate-0002-up` and `-- name: migrate-0002-down` sections creating `agent_session` and `agent_event`:
  ```sql
  -- name: migrate-0002-up
  CREATE TABLE agent_session (
      session_id VARCHAR2(128) NOT NULL,
      app_name VARCHAR2(128) NOT NULL,
      user_id VARCHAR2(128),
      state CLOB DEFAULT '{}' NOT NULL,
      created_at TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP NOT NULL,
      updated_at TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP NOT NULL,
      CONSTRAINT pk_agent_session PRIMARY KEY (session_id),
      CONSTRAINT chk_agent_session_state_json CHECK (state IS JSON)
  );

  CREATE INDEX idx_agent_session_app_user ON agent_session(app_name, user_id);

  CREATE TABLE agent_event (
      id VARCHAR2(128) NOT NULL,
      session_id VARCHAR2(128) NOT NULL,
      seq NUMBER(10) NOT NULL,
      turn VARCHAR2(128) NOT NULL,
      agent VARCHAR2(128) NOT NULL,
      content CLOB NOT NULL,
      actions CLOB,
      created_at TIMESTAMP WITH TIME ZONE DEFAULT SYSTIMESTAMP NOT NULL,
      CONSTRAINT pk_agent_event PRIMARY KEY (id),
      CONSTRAINT fk_agent_event_session FOREIGN KEY (session_id)
          REFERENCES agent_session(session_id) ON DELETE CASCADE,
      CONSTRAINT uq_agent_event_session_seq UNIQUE (session_id, seq),
      CONSTRAINT chk_agent_event_content_json CHECK (content IS JSON),
      CONSTRAINT chk_agent_event_actions_json CHECK (actions IS NULL OR actions IS JSON)
  );

  CREATE INDEX idx_agent_event_session_seq ON agent_event(session_id, seq);

  -- name: migrate-0002-down
  BEGIN
      FOR t IN (SELECT table_name FROM user_tables WHERE table_name IN ('AGENT_EVENT', 'AGENT_SESSION')) LOOP
          EXECUTE IMMEDIATE 'DROP TABLE ' || t.table_name || ' CASCADE CONSTRAINTS PURGE';
      END LOOP;
  END;
  ```

  ```sql
  SELECT COALESCE(MAX(seq), 0) + 1 AS next_seq
  FROM agent_event
  WHERE session_id = :session_id;
  ```
