## Objective

Fix defects `AI-08`, `AI-09`, `AI-16`, `AI-17`, and `PL-07` in `src/app/domain/ai/a2a/` by:
1. Implementing `build_a2a_call_context(context)` so unauthenticated A2A requests resolve a deterministic `"anonymous"` owner ID (instead of `<UnauthenticatedUser object at 0x...>`) and inherit `X-Session-ID` when supplied.
2. Injecting or resolving the existing Dishka container cleanly without calling `create_container()` on every fallback request (`executor.py:61-66`).
3. Using `TaskUpdater` (`start_work`, `add_artifact`, `complete`, `failed`, `cancel`) in `CoffeeAgentExecutor.execute` and `cancel`.
4. Parameterizing `build_agent_card(base_url: str = ...)` in `src/app/domain/ai/a2a/card.py` so the A2A agent card URL is derived from `settings.app.URL` rather than hardcoded to `http://localhost:8000`.

## Context

- `src/app/domain/ai/a2a/executor.py:85-90` computes `user_id = str(scope.get("user") or UnauthenticatedUser())`. Because `UnauthenticatedUser` has no `__str__` override, every request gets a distinct memory address string, so subsequent `tasks/get` or `tasks/cancel` calls fail `InMemoryTaskStore` ownership checks (`AI-08`).
- `src/app/domain/ai/a2a/executor.py:61-66` calls `make_container()` when `dishka_container` is not on `asgi_scope["state"]`, creating a new `Scope.APP` container and Oracle connection pool that is never closed (`AI-09`).
- `src/app/domain/ai/a2a/card.py:21` hardcodes `url="http://localhost:8000/a2a"` (`AI-17`).
